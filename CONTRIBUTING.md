# Contributing to D-Droidify

Thank you for your interest in contributing!

**D-Droidify** is a specialized fork of [Droid-ify](https://github.com/Iamlooker/Droid-ify) focused specifically on Dhizuku support and automated builds.

---

### Scope of This Repository

Please submit **Issues**, **Feature Requests**, and **Pull Requests** here **only** if they are related to:

* **Dhizuku Support:** Bug/crash reports, improvements, or updates related to Dhizuku installation, permissions, and `HiddenApiBypass`.
* **Build & Deployment:** Fixes and enhancements to GitHub Actions, CI/CD workflows, signing, and release automation.
* **Fork-Specific Configuration:** Issues regarding the custom F-Droid self-update repository or package rebranding (`io.github.ilhan.droidify`).

---

### General Bugs & Upstream Features

For general UI/UX feedback, translations, upstream F-Droid client features, or bugs unrelated to Dhizuku:

👉 **Please report or contribute directly to the upstream repository:**  
**[Iamlooker/Droid-ify](https://github.com/Iamlooker/Droid-ify)**

*Issues and pull requests outside the scope of Dhizuku integration or this fork's build pipeline will be closed and redirected upstream.*
